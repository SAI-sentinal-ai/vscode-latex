# VS Code settings for LaTeX

A quiet, minimal VS Code setup for writing LaTeX documents, with the usual clutter removed and softer syntax colours. It is for my own writing, and anyone who wants the same.

The repo also holds a sample article (`article.tex`, `bibliography.bib`, `naturetex.sty`) to try it on.

## Use it

1. Install the [LaTeX Workshop](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop) extension.
2. Install the [Monochrome theme](https://marketplace.visualstudio.com/items?itemName=anotherglitchinthematrix.monochrome).
3. Install the Adobe Caslon Pro font, or the free Cormorant Garamond.
4. Copy the `.vscode` folder into the folder that holds your `.tex` file, then open that folder in VS Code.

The M Fell English font for the document should install itself on the first run.
